## فایل‌های اجرایی/ایجنت در ریشه

- `AGENTS.md` — قرارداد مشترک و انگلیسی برای coding agentها.
- `CLAUDE.md` — قواعد اختصاصی Claude Code؛ فایل `AGENTS.md` را وارد می‌کند.
- `.nvmrc` و `.node-version` — نسخه‌ی Node.js هدف: `24.21.0`.

## قواعد ثابت پروژه

1. هیچ ایموجی‌ای در UI و عناوین استفاده نمی‌شود؛ فقط آیکون کتابخانه‌ای.
2. هر جدول دامنه‌ای `conference_id` دارد و هر کوئری اجباراً scope می‌شود.
3. هیچ متن فارسی/انگلیسی داخل کد سخت‌کد نمی‌شود؛ همه از لایه‌ی ترجمه می‌آید.
4. هر تغییر وضعیت، یک رکورد در `status_history` و هر اقدام حساس یک رکورد در `audit_logs` می‌سازد.
5. خروجی AI همیشه با برچسب «استخراج خودکار» و امکان اصلاح انسانی ارائه می‌شود.
6. سرویس AI مسیر تنزل (Degraded) بدون اینترنت دارد؛ مقاله‌ی واقعی بدون مجوز به provider بیرونی فرستاده نمی‌شود.
7. هیچ فایل مقاله‌ای با URL مستقیم سرو نمی‌شود؛ فقط لینک امضاشده‌ی کوتاه‌عمر.
8. در MVP هیچ درگاه پرداختی متصل نمی‌شود؛ اتصال API پس از MVP و تست‌شدن محصول انجام خواهد شد.
9. حالت داوری و سقف تعداد مقاله برای هر حساب ارسال‌کننده در سطح همایش قابل تنظیم است؛ تاریخ گواهی عددی و نوشتاری است.
10. سایت شرکتی، سایت همایش و پنل‌ها از یک سیستم طراحی مشترک و پوسته‌های متناسب با نوع اپ استفاده می‌کنند.
11. هیچ درخواست به مدل/سرویس بیرونی که احتمال هزینه دارد ارسال نمی‌شود مگر هزینه‌ی صفر یا پوشش سهمیه‌ی رایگان برای همان مسیر و مدل تأیید شده باشد؛ سبزشدن تست دلیل رایگان‌بودن نیست.

## تصمیم‌های ثبت‌شده

- مدل استقرار: یک کدبیس، نصب مستقل روی سرور هر دانشگاه، با داده/برند قابل تنظیم.
- نسخه‌های پایه تا شروع bootstrap: Node.js `24.21.0` · Next.js `16.3.x` · NestJS `12.1.x` · Prisma `7.x` پایدار · PostgreSQL `18.x`؛ exact package/image versions در lockfile و digest قفل می‌شوند.
- جهت بصری: سایت شرکتی Neumorphism نرم · سایت عمومی همایش Glassmorphism کنترل‌شده · پنل‌های دانشگاهی Claymorphism.
- پالت پیشنهادی: Indigo `#5B57D9` · Teal `#139A8A` · Violet `#9573E9` · Canvas `#F5F6FB` · Ink `#202641`.
- قواعد محصول: بدون درگاه در MVP · حالت داوری قابل تنظیم per conference · تاریخ گواهی در هر دو قالب · سقف مقاله per conference قابل تنظیم، مقدار خالی یعنی بدون سقف.
