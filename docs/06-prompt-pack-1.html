سند ۰۶ — بسته‌ی پرامپت شماره ۱ برای Claude Code

پرامپت‌ها انگلیسی و مرحله‌ای نوشته شده‌اند تا به Claude Code داده شوند. این بسته برای آماده‌کردن اسکلت قابل‌تست ریپو است؛ دستورها را یک‌جا paste نکن و هیچ‌کدام را پیش از موفقیت smoke test ابزار اجرا نکن.

وضعیت: پیش‌نویس · روی مدل کاربر اجرا/اعتبارسنجی نشدهمدل هدف: Node 24 · Next 16 · Nest 12 · Prisma 7داده‌ی واقعی: ممنوع در تست

۱قاعده‌ی استفاده

Gate صفر: ابتدا مسیر مستقیم AgentRouter/Claude Code را در بند ۷ سند ۰۵ بررسی کن. پیش از هر درخواست مدل، هزینه‌ی صفر یا اعتبار رایگان کافی باید در حساب تأیید شود؛ نمایش API Usage Billing یا سبزشدن اتصال اثبات رایگان‌بودن نیست. اگر هزینه‌ی صفر تأیید نشد، هیچ‌یک از coding prompts را اجرا نکن. پس از تأیید هزینه، smoke test ابزار را انجام بده.
  1. هر بار فقط یک پرامپت را داخل clone واقعی مخزن محصول اجرا کن.
  2. بعد از هر مرحله، diff و گزارش تست را بررسی کن؛ بعد مرحله‌ی بعد را paste کن.
  3. کلید API، `.env`، مقاله‌ی دانشگاه یا مشخصات شخصی را داخل prompt قرار نده.
  4. اگر مدل از تصمیم سندها خارج شد یا درباره‌ی destructive operation سؤال دارد، اجازه نده حدس بزند؛ کار را متوقف کند.
قانون GitHub برای همه‌ی پرامپت‌های کدنویسی: فقط روی branchای کار کن که از قبل checkout شده؛ branch نساز/عوض نکن و `git init` نزن. پیش از تغییر، Git root، `origin`، branch و status را بررسی کن. پس از پاس‌شدن تست‌ها، فقط فایل‌های همین تسک را stage کن، diff و secret را بازبینی کن، commit بساز و به همان branch در `origin` push کن. در صورت نبود Git/remote، خطای تست یا ردشدن push توقف کن؛ force-push و branch جایگزین ممنوع. P0 فقط‌خواندنی است و commit/push نمی‌کند.

ترتیب پیشنهادی

P0 بررسی فقط‌خواندنی → P1 workspace root → P2 دو اپ وب → P3 API health shell → بازبینی diff و CI.

عمداً خارج از این بسته

ساخت schema نهایی و migrationهای دامنه، درگاه پرداخت، deploy/backup production، و auth/RBAC کامل. سند ۰۲ هنوز پیش‌نویس است و شناسه‌ی ورود/جدول نشست refresh باید پیش از پیاده‌سازی auth نهایی شود.
